# Security policy

Omarchy Enterprise 0.5.0 is experimental and has no production support commitment. See
the [availability matrix](docs/availability.md) before evaluating
administrative workflows.

Use **Security → Report a vulnerability** on the GitHub repository when private
vulnerability reporting is enabled. If it is unavailable, contact the
maintainers through a private channel before sending details. Use minimal
synthetic reproduction steps and omit credentials, tickets, keytabs, private
logs and infrastructure details from reports.

Keep the graphical tools in the regular desktop session. Review current
state and obtain fresh approval for installed administrative commands. Keep
protected local recovery material and reconcile interrupted operations before
retrying. Verify package signatures and signing identity separately from
source checksums.
